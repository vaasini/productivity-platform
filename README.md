# Engineering Productivity Platform

TypeScript monorepo scaffold for the Engineering Productivity Platform.

## Workspaces

| Package | Path | Role |
|---|---|---|
| `@eng-platform/frontend` | `packages/frontend` | React + Vite SPA |
| `@eng-platform/backend` | `packages/backend` | Express API |
| `@eng-platform/shared` | `packages/shared` | Shared TypeScript types/utilities |

## Commands

```bash
npm install
npm run build
npm run lint
npm run test
```

Requires Node.js 20.x (see `.nvmrc`).
